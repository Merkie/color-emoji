# Emoji artwork

The bundled emoji PNGs are derived from Apple Color Emoji through
[apple-emoji-ttf](https://github.com/samuelngs/apple-emoji-ttf), release
`macos-26-20260722-484daf4e`. Apple Color Emoji assets and designs belong to
Apple Inc. The font conversion project's MIT license does not grant rights
to Apple's artwork.

The sequence list was generated using Unicode's Emoji 18.0 `emoji-test.txt`.
The font, Unicode data, and Python packages are build-time inputs to
`tools/emoji.py`; none are downloaded when Minecraft runs.
